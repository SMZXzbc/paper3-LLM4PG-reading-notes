## 🔍 LLM4PG 速览

**一句话总结**：让大模型看"无人机拍的 RGB 图 + 深度图"→ 直接生成"信号覆盖图"（Pathloss Map）

### 核心创新：机器的联觉（SoM）
把人类的"联觉"概念搬到机器上——让 AI 同时理解：
- 👁️ **视觉**：建筑物长什么样、离地面多远
- 📶 **电磁**：信号频率是多少（1.6GHz vs 28GHz）
- 🗺️ **输出**：这个位置信号有多强

### 模型架构：三条流水线
```
[输入] → [Embedding模块/翻译官] → [LLM Backbone/大脑] → [Decoder模块/画图师] → [Pathloss Map]
```

| 模块 | 作用 | 关键技术 |
|:---|:---|:---|
| Embedding | 把图片+频率翻译成 LLM 能懂的 token | ViT 切图 + MLP 编码频率 |
| LLM Backbone | 学习"物理环境 → 电磁空间"的映射关系 | GPT-2，冻结前6层，微调其余 |
| Decoder | 把电磁特征还原成路径损耗热力图 | 转置卷积上采样 ×3 |

### 数据集：SynthSoM-U2G
- **规模**：9,490 张路径损耗图 + 5,660 张 RGB/深度图
- **场景**：十字路口（建筑密集）+ 宽马路（建筑更高更密）
- **频段**：1.6GHz（低频，绕射强）+ 28GHz（毫米波，易遮挡）
- **高度**：50m / 70m / 200m

### 实验结论
> LLM4PG 在所有测试条件下都比传统 AI（GAN/ResNet）准得多，**RGB + 深度图一起用效果最好**。
